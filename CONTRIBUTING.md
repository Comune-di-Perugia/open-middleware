# Contributi

Quando il repository pubblico è disponibile, usare il sistema di segnalazioni per proporre una modifica o segnalare un problema non riservato.

Per contribuire, aprire una richiesta di integrazione che descrive la modifica e le verifiche eseguite. Il [documento di sviluppo](docs/sviluppo.md) indica come compilare le soluzioni.

Non allegare credenziali, configurazioni locali o dati di produzione. Il [file SECURITY.md](SECURITY.md) indica come gestire le segnalazioni riservate.
